# App Install History — Cloud Build

## GitHub Codespaces
1. Put this project in a GitHub repository.
2. Open the repository in GitHub Codespaces.
3. Wait for the Android SDK setup to finish.
4. Open the terminal and run:

   ./build-apk.sh

5. Download `app/build/outputs/apk/debug/app-debug.apk` from the file explorer.

No Android Studio is required.
